# smartcart-customer-segmentation-unsuperwised

SmartCart Customer Segmentation is an unsupervised machine learning project that groups e-commerce customers based on their purchasing behavior, engagement level, and loyalty indicators.

The system analyzes historical customer data to identify meaningful customer clusters, helping businesses improve personalized marketing, customer retention, and data-driven decision-making.

## Problem Statement
SmartCart is a growing e-commerce platform that currently uses generic marketing strategies for all customers. This project aims to segment customers using clustering algorithms to better understand customer behavior patterns.

## Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  

## Machine Learning Approach
- Data Preprocessing
- Feature Scaling
- Unsupervised Clustering (K-Means / Hierarchical)
- Cluster Analysis & Visualization

## Outcome
- Identified distinct customer segments
- Improved understanding of high-value and churn-prone customers
